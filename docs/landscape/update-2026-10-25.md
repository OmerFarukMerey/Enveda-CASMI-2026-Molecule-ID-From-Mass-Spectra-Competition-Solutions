## 3. Does a single change explain 0.466 → 0.467? Yes [V for the code, I for the mechanism]

alexchilton's notebook, once unwrapped, is n1 with one constant changed. Fusion is `1/(o + baseline_rank) + 0.25/(o + neural_rank)`
over the final 25.
- **o = 1:** the worst fused score of baseline rank 1 is 0.5 + 0.25/26 = 0.510, and the best score rank 2 can reach is 1/3 + 0.25/2 = 0.458.
  So **the baseline top-1 can never move**, and the neural model only re-orders ranks 2 to 25. Ranks 2 and 3 can still swap.
- **o = 1.5** (rajrajak99): 0.400 + 0.009 = 0.409 > 0.286 + 0.100 = 0.386, so the top-1 is also locked. This scored 0.467 too.
- **o = 3** (n1): 0.250 + 0.009 = 0.259 < 0.200 + 0.063 = 0.263, so the baseline rank-2 candidate with neural rank 1 can take rank 1
  when the baseline leader's neural rank is 18 or worse. Rank 3 can never reach rank 1. On the visible set, n1 changed 1 top-1.

Our reading: n1's +0.001 over s1 comes from re-ordering ranks 2 to 25. The rare top-1 flips at o = 3 lose a little, and locking them
gives the next +0.001. That is about 1/8 of one molecule moving to rank 1, so it is noise-sized but consistent across two
independent offsets [I].

Public sweep of the same model on the same frozen baseline (weight w, offset o):

| w / o | 0.15 / 3 | 0.20 / 3 | 0.25 / 3 | 0.25 / 1.5 | 0.25 / 1 | 0.25 / 10 | 0.5 / 3 (on v2) | 0.75 / 3 |
|---|---|---|---|---|---|---|---|---|
| public | 0.465 (×4 notebooks) | 0.466 (×2) | 0.466 | **0.467** | **0.467** (×3 runs, one code) | 0.446 [C] | 0.444 | 0.419 [C] |

The fusion helps only when it is light and steep. Anything that lets the neural model reach the top-1 more often loses (0.5: −0.021;
0.75: −0.047; o = 10: −0.020), which is consistent with sanpier v14 / lavinwins v6 "main top-1 protection" at 0.404 being a different and
broken mechanism. Next candidates by the same logic [I]: o = 1 with w 0.30 to 0.35. At o = 1, w can rise to 0.36 before the
top-1 lock breaks (it needs 1/2 − 1/3 > w·(1/2 − 1/26)). Nobody has published this yet.
