## 3. Ranked improvement ideas on top of fusion-v4n

**How to evaluate.** "Re-fuse" means the change touches only `fusion_core` inputs already in `stage_cache/` (or is a cheap pure
function of cached candidates and spectra), so `tools/refuse.py` can grid it in seconds. "Heavy run" means a new Kaggle run
with stage recomputation. The visible test is a train-drawn placeholder (all library hits), so re-fusion on it only checks
plumbing. Paired local deltas need a `VALIDATION=True, FULL_ON_COMMIT=True` run: enveda-np-examples structures held out
and their spectra purged from the library. Artefacts saw these structures, so this is a leaky proxy, but useful for
*paired* comparisons. At n = 250 its SE is about ±0.015. Given the LB noise (±0.016 per difference), **bundle** changes
that each have offline support rather than probing one knob per submission.

**Runtime baseline.** On our 12-molecule T4 smoke run, ICEBERG scored 40 predictions/s and GLACIER 83/s, at ~2 predictions per
candidate (1,526 predictions for 773 candidates; `runs/v1-smoke/*_work/*.meta.json`). For ~400 molecules at ~64 candidates
each, that is roughly 21 min ICE and 10 min GL. Neither is near the 5400 s / 4000 s budgets. seyit's notebook states
~2–2.5 h for v4g + engine-2, so the full reference plausibly runs about 3–4 h, leaving ≥ 5 h of headroom. **This estimate is
not verified.** Record the real number from the next full run's `run_manifest.json`.

**Suggested order.**
1. One heavy `VALIDATION=True, FULL_ON_COMMIT=True` run that also dumps `pids` and a deeper `TOPN`. This gives cached stage outputs for ideas 1–5 and 8, plus the rank > 60 statistic for idea 7.
2. Grid ideas 2–4 and λ_frag locally with paired deltas.
3. Submit one bundle of everything that is non-negative on VALIDATION: frag term + λ retune + library-hit skip + μ 0.15.
4. Keep the plain reference (or bob's +pool μ) as the safe second final-submission pick.

Ideas 6 and 7 are the next heavy runs if the bundle holds.
