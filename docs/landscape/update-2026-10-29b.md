# Landscape update, 2026-10-29 (b): what the 0.477 authors tried, and why a better neural model is not a ticket

Companion to [update-2026-10-29.md](update-2026-10-29.md) (the public notebooks at 0.477 and the leaderboard); this note keeps only what
that one does not cover. Marks: **[V]** read in code, the API or output files; **[C]** claimed by an author, not checked; **[I]**
inference. Notebooks were read as data only; nothing downloaded was executed.

## 1. heliosli overlay v4 [V code, C claims]

Code identical to romanrozen V2 (13 of 13 code cells) plus one final cell. FREEZE rule unchanged from v3: every training-set candidate
keeps its slot; the others are re-ordered by z(-log rank) + alpha z(re-ranker); lists with `library_max >= 0.9` are untouched; a
three-molecule self-test gates the overlay. New in v4: the re-ranker reads each query through dmitriigluzdov's five fold-safe
FPNets and averages the five views; "trained on queries routed to the one encoder that never saw their structure". `rr_deploy4.py`,
`rr_v3.py`, the checkpoint and the config come from a private dataset (`''` in the metadata): not runnable by anyone else.

## 3. The long-trained model is a better scorer and a worse fusion input [V]

On external CC0 spectra that are not copies of train spectra (senanuretin's GNPS2 / MassBank 2026.03 snapshots; near-copies with
cosine >= 0.90 to a train spectrum of the same structure removed; each structure against 255 decoys, same formula first), scored as
`neural_scores.py` scores a list:

| set | sanpier final_model.pt (LB-good) | Ahmed Berat Özer long final_model.pt (LB -0.011 / -0.019) |
|---|---|---|
| XS: 171 train structures, new spectra | MRR@25 0.237, top-1 0.094 | 0.423, 0.263 |
| XU: 24 structures absent from train | 0.204, 0.042 | 0.517, 0.333 |

Stand-alone retrieval quality does not predict the fused leaderboard score on this line [I]: the baseline's networks are trained on
all of train (dmitriigluzdov's fold-safe FPNets rank 97% of seen molecules first against 68% of a held-out fold), and a neural model
that memorises the same structures adds correlated rather than independent evidence. Tool: `xbench.py` (session scratch).
