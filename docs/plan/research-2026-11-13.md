## 4. New measurement: the direct-hit rule on the Enveda NP panel [V]

Why: the overlay is the only mechanism with board evidence, and its private effect is about 2.2 times its public exposure. Before
changing or trusting it we need its precision in both situations: the answer has reference spectra, and it has none.

Setup (`ext.py`, `ana.py`, `ana2.py`; CPU, about 5 min): queries = the 1,184 `enveda-np-examples` spectra of 250 structures (timsTOF,
the closest public set to the test). References = all 127,137 non-Enveda train spectra (8,494 structures) inside the queries'
precursor windows, same ion mode. The overlay's exact rule: best cosine over the molecule's spectra, >= 4 matched peaks.
"Truth-absent" = the same after deleting every reference of the true structure (a class-2 / class-3 stand-in).

| TAU | With references: fires / correct / wrong | Precision | Truth absent: fires (all wrong) of 250 |
|---|---|---|---|
| 0.70 | 236 / 211 / 25 | 0.894 | 123 (49%) |
| **0.80** | **211 / 192 / 19** | **0.910** | **90 (36%)** |
| 0.85 | 195 / 180 / 15 | 0.923 | 68 (27%) |
| 0.90 | 143 / 132 / 11 | 0.923 | 34 (14%) |

- Inside the band that carried the public gain, [0.80, 0.85): 16 fires, 12 correct with references; 22 false fires without.
- 71 of the 90 false fires at 0.80 are same-formula isomers of the answer.
- Best true-reference cosine per molecule: 139 at >= 0.90, 50 in 0.85 - 0.90, 15 in 0.80 - 0.85, 22 in 0.70 - 0.80, 21 below 0.70,
  3 with no usable reference. So 46 of 250 known NPs have no true match at 0.80 with all of train as the library.

Variants of the rule (same data):

| Rule at TAU 0.80 | With references: fires / correct / wrong | Truth absent: fires |
|---|---|---|
| plain | 211 / 192 / 19 | 90 |
| best - second-best structure >= 0.05 | 159 / 153 / 6 | 65 |
| margin >= 0.10 | 126 / 123 / 3 | 47 |
| the same structure at >= TAU - 0.1 in two of the molecule's spectra | 184 / 171 / 13 | 64 |
| + merged references (all energies of one structure / adduct / library / instrument summed) | 212 / 196 / 16 | 92 |

Reading [I]:
- When the answer has reference spectra the rule is right nine times in ten. When it has none, **one NP-like molecule in three
  still has a wrong isomer above 0.80**. No threshold, margin or agreement rule separates the two cases: each removes correct and
  false fires in about the same proportion.
- The overlay only matters where its pick differs from the pipeline's rank 1, and train already contains most of these references,
  so most fires change nothing. That fits the flat public ablations. It also means the public +0.006 says little about the private
  sign: the private part will contain about two "band" events, each +0.0027 (rank 4 to 1) or -0.0018 (a correct leader pushed to 2).
- Merging references across collision energies (the test spectra are merged acquisitions, host answer in 753419) does **not** help:
  +1 correct crossing, +2 wrong crossings. Dropped.
- Caveat: these 250 are common natural products with many isomer references. Rarer hidden molecules probably have fewer false
  fires. The harm figure is an upper bound, the precision figure is not.

## 5. Architecture proposals, ranked by expected private gain per hour

Numbers are my estimates unless marked. "Private" means the 276-molecule part. None of these is expected to show on the public
board; that is the point of section 2.

### A1. Know what the overlay does on our own lists, then decide TAU / margin from that (CPU, 0.5 - 1 day)
- **Idea.** Port cell 24 to the local replay and run it on real final lists where we hold labels: the clean instrument's 600 lists
  (`casmi-work/clean/replay/`) and the s1val lists, once with every reference available and once with the answer's references
  removed. Count the lists where the overlay changes rank 1, and who was right: pipeline or overlay. Use train's non-Enveda
  spectra as the reference set first (on disk), the two public datasets when approved (D1).
- **Evidence.** Section 1 (the only board gain on this line), section 4 (0.91 / 36%).
- **Expected.** The measurement itself is worth more than any variant: it tells us whether ax13's overlay is a private asset or a
  private risk. If rank-1 changes are net positive in both arms, keep TAU 0.80. If the truth-absent arm shows correct leaders
  displaced, the candidate is "margin >= 0.05, otherwise insert at rank 2 and keep the leader", estimated -0.002 to +0.004 private.
- **Cost.** CPU only. Kaggle: nothing new (the cell runs 30 s).
- **Deciding test.** Pre-register: on the panel half of the clean instrument (the half that predicted LB signs), paired delta >= 0
  with wins > losses in the with-reference arm **and** delta >= 0 in the truth-absent arm. Either arm negative: no variant.
- **Must avoid.** s1vg2 / n1a: do not let a single public +0.001 override a negative local arm. sp2: 11 wins / 0 losses on the
  enveda-180 half predicted nothing; judge on the panel half only.

### A2. Make the scored run deterministic with respect to time guards (Kaggle CPU/GPU quota, 2 - 4 h, no submission)
- **Idea.** The pipeline skips optional stages when its guards trip (`TIME_GUARD_HOURS = 7.5`, `PHYSICAL_POST_SECONDS = 1500`,
  per-overlay budgets). The author reports about 0.002 between reruns of identical code [C]. Run ax13 once privately with the
  fast-commit path switched off on the visible 400-molecule file (same size as the hidden test, host 756064), log each stage's
  wall time against its guard, and note which stages are within 20% of being skipped. Caveat: the visible molecules are
  enveda-180 library hits, so stages that only run below the library gate will look cheaper than on the hidden test; read
  the per-molecule cost of those stages from the log and scale it.
- **Expected.** No mean gain. It removes a +/- 0.002 coin flip, which is the width of the 668-team tie.
- **Deciding test.** Stage log: all stages complete with >= 20% slack. If not, reorder so the cheap overlay cells run before the
  expensive optional ones, and resubmit once (needs approval; same expected score).
- **Must avoid.** Any change to weights or thresholds in the same run.

### A3. Adduct bridge for the direct-hit rule (CPU, 0.5 day, only if A1 says the overlay is an asset)
- **Idea.** Cell 24 computes the query's neutral mass and never uses it: it matches on precursor m/z, so an `[M+NH4]+`,
  `[M-H2O+H]+` or `[M+Na]+` spectrum can only meet a reference of the same adduct, and the MassBank source is reduced to
  `[M+H]+` / `[M-H]-` by construction [V]. coverage-2026-10-02 measured that `[M+NH4]+` and water-loss spectra score like
  `[M+H]+` against `[M+H]+` predictions. Match those two adducts against `[M+H]+` references by neutral mass.
- **Evidence.** zz3t3rn41's V50 has an adduct-aware tier at 0.487, so no public loss and no public gain [C]. Exposure: molecules
  without an `[M+H]+` or `[M-H]-` spectrum; evgap-2026-10-24 has the adduct segments.
- **Expected.** 0 to +0.002 private. Small, but it is the same mechanism as the only real gain.
- **Deciding test.** A1's harness restricted to panel molecules after deleting their `[M+H]+` / `[M-H]-` queries: correct fires
  gained against false fires gained in the truth-absent arm. Ship only at >= 3 : 1.
- **Must avoid.** msfwd / adductfwd: the surrogate signal was "above chance" and still failed in replay. Require the replay.

### A4. Class-3 insert below rank 1 from a formula-constrained decoder (Kaggle GPU quota 20 - 40 h, 1 - 2 weeks; long shot)
- **Idea.** The only place where the top 20 can plausibly be finding 0.02 - 0.05 is the half of the test that scores about zero
  (coverage2 / evgap: about 40% of answers in no database, 13% PubChem-only). heliosli's decoder v3 (fingerprint-conditioned,
  256 samples, verifier on the panel) reaches "top = truth 14%" on unseen NPs [C] and inserts at rank 2 or 3 only above p 0.47.
  Our own version: SMILES decoder pretrained on COCONUT + PubChem-tier structures (structure-only pretraining is allowed, 751373),
  conditioned on the fold-safe FPNet output and the rank-1 formula; insert at rank 3, never rank 1.
- **Evidence against.** I2 probe 0.007 (one new rank-1 hit in 124), GEN lost, ae1 / ae2 neutral, FRIGID pilot KILL, two forum
  negatives (section 3), heliosli's whole stack +0.001. Probability of a real gain: about 15%.
- **Expected.** If it works: +0.003 to +0.010 private (a rank-3 hit is +0.0012 each). If not: about -0.001 from displaced tails.
- **Cost.** Training fits Kaggle's weekly T4 quota, so the shared PC is not needed. Inference about 20 - 30 min for 400 molecules.
- **Deciding test.** Neighbour-removed validation as in forum 756504 / 748524: remove the answer **and** every structure with
  Tanimoto >= 0.7 from the decoder's training set and from the pool; panel NPs absent from MassSpecGym. Gate: inserted pick = truth
  in >= 8% of fired lists at a fire rate >= 15%, and the clean-instrument replay (answer present) loses < 0.001.
- **Must avoid.** Pitfall 6 (delete-and-regenerate overstates reach 3x); GEN (insertion above database answers).
- **Recommendation.** Start only if the user wants a shot at gold rather than a safer silver / bronze attempt. It is the one
  proposal here that could move more than two molecules, and the one most likely to return nothing.

### A5. Not proposed (and why)
- Any new last-stage reranker or veto (isoxe, FREEZE, RR): ours -0.005 to -0.026, public -0.020, clean replay negative.
- More scorer seeds, longer training, scaffold-fold scorers: -0.008 to -0.019 on five tickets.
- MIST (`mist_msg_noaug`): the host approved it on 11-11 (757307), but mist-2026-10-04 found it does not lift unseen answers in the
  PubChem window, and third fingerprint lists elsewhere scored +0.005 / -0.005 to -0.012.
- MS2DeepScore triangulation, DreaMS heads, GLACIER fine-tune, timsTOF CE calibration, adduct-set likelihood, chemistry rules:
  all measured and failed between 10-06 and 10-24.
- SpecBridge (arXiv 2601.17204, DreaMS aligned to frozen ChemBERTa): withdrawn by its authors on 2026-03-03 for an evaluation
  error. GLMR (AAAI 2026): no released weights found. Neither is usable.
- Merged-energy references: section 4, no effect.

Why it does not work:
- **Edges do not mean similar structures.** 280 edges at cosine >= 0.6: true-structure Tanimoto median 0.19, 12% at >= 0.5

- **The families exist but the spectra do not find them.** Among the 600 there are 118 pairs with true Tanimoto >= 0.5 (113
  molecules, 109 of them in the NP panel) and 356 pairs at >= 0.35. The modified cosine at 0.6 finds 34 and 51 of them.
- **Ceiling with perfect edges** (an oracle links exactly the pairs with similar true structures; the lists as they are): pairs
  at >= 0.5: +0.0014 at lambda 0.25 (10 / 2), +0.0027 at lambda 0.5; pairs at >= 0.35: +0.0035 (28 / 2), **+0.0100 at lambda 0.5
  (35 / 4)**. With perfect edges and the neighbours' true structures: up to +0.026. The idea has a real ceiling, but it needs a
  spectrum-pair similarity with precision above about 0.6 at useful recall. Neither kernel we may use gets past 0.44 at 25% recall.
- **Who gains under the published rule**: lists whose best neighbour is correct at rank 1: 150 lists, +0.04 RR (5 / 4); lists
  with no correct neighbour: 67 lists, +0.32 RR (7 / 2). The gain does not come from correct neighbours. That is what noise looks like.
- This repeats `reviews/testnet-2026-10-07.md` with a different rule on different lists (19% of panel molecules had a real analog
  as best neighbour at 0.7; oracle ceiling +0.004). Two independent measurements, the same answer.

Pitfalls of testing network variants on the 600, and how each was handled:
- **Density.** Edges grow with the square of the set size: 217 of the 600 lists have a neighbour, a random 400 of them 118 on
  average, a random 124 only 17. The visible placeholder has 114 of 400, the same as a random draw of ours, but it is train
  data and says nothing about the hidden set. Simulation: 300 random draws of 400 and of 124 molecules from the 600, edges
  restricted to the draw. N-1c: 400-draw mean +0.0002, sd 0.0007, negative in 29% of draws; 124-draw mean -0.0001, sd 0.0013,
  exactly zero in 21%, negative in 39%. Lambda 0.5: 400-draw -0.0064 (negative in 99%), 124-draw -0.0027 (negative in 74%).
  The public +0.001 is one draw from a distribution centred on zero.
- **Composition.** 350 of the 600 are enveda-180 (synthetic library compounds, no families: 4 of the 113 molecules in a similar
  pair). The families are in the 250-molecule NP panel. A hidden set drawn from few extracts could be denser than the panel,
  and no resampling of our lists can imitate that. The board is the better witness: on a family-rich set lambda 0.5 should
  gain, and it lost 0.004. Read panel and enveda-180 separately, and treat a gain that appears only on enveda-180 as noise.
- **Neighbour quality.** The 600 answers are all train structures held out from the clean pipeline, so neighbour lists are
  about as good as for class 1 / 2 of the test and better than for class 3. The oracle rows show this does not matter: even
  perfect neighbour answers do not help with these edges.
- **MS2DeepScore** was trained on GNPS / MassBank / MoNA / MSnLib (CC BY 4.0; no NIST in training per
  `docs/landscape/allowed-models-2026-10-24.md`). These libraries hold many panel structures, so its panel numbers are optimistic.
- **Many variants, tiny effects.** Twenty-odd variants around +/- 0.001 on 600 lists: the best row is selection noise. I name no
  variant as better than the published one.
