## 1. Rule [V `scratch/land1027/fz_core.py`]

The idea is heliosli's: two protections around an isomer reranker. The notebook is "happy-to-make-the-dataset-public-if-it-helps",
which scored v1 0.471 and v2 0.475 on the public 0.468 V2 notebook. Their model and code are private, and nothing was copied. Our version:
- **Library skip.** If `library_max` >= 0.9, the list is left unchanged. `library_max` comes from the pipeline export
  `frozen_candidate_evidence.parquet`, which exists in sp1 / sp2 (= `finite(BASE[mid][2]) or 0`).
- **Freeze.** Any candidate whose plain InChIKey14 is in the freeze set keeps its slot. The plain InChIKey14 = train.parquet's
  `inchikey14` (2000 / 2000 checked).
- **Re-order.** The other candidates that have an isoxe score are grouped by formula. In each group of 2 or more, the group's own
  slots are reassigned by `1/(3+b) + a/(3+x)`, where b = list position and x = isoxe rank in the group. Primary a = 1, and rank 1 may move.

Freeze sets, chosen to emulate "the answer is not a training structure":

| Instrument | Freeze set | Why |
|---|---|---|
| Clean | train − E | E = 21,917 structures |
| s1val | train − the 400 answer keys | With the full train set every answer is frozen, so Δ = 0 by construction. That was checked: 0 / 0 changes. |
| Notebook | full train | |

The base lists were regenerated with replay_sp.py's own overlay code (neural bound P, tail off). Every rank matched
`casmi-work/sp2/rows.parquet` (asserted). There is no sanpier neural re-order.
