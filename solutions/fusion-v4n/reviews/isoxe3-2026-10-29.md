## 1. What was built [V]

| Part | What |
|---|---|
| Unit | one formula group as fz_core groups it (non-frozen, v2-scored, same formula, size ≥ 2, list not library-skipped) |
| Action | fz_core's RRF re-order of that group's slots, 1/(3+b) + a/(3+x). Configs A05 / A10 (a 0.5 / 1.0) and A05L / A10L (rank 1 never moves) |
| Label | Δ RR of the answer when only that group is re-ordered (0 for groups without the answer) |

| Model | L2 logistic (C 0.1) on standardised features, trained on Δ ≠ 0 groups, y = Δ > 0, weight abs(Δ); move iff p ≥ 0.5; < 20 rows -> never move |

| Split | answer Murcko scaffold; held-out F = scaffold groups by sha256 order until ≥ 30% (180 molecules, 164 scaffolds); Dv 420 (374 scaffolds); CV 5 folds by scaffold hash × 4 repeats |
| Code | `clean/isoxe_gate.py` (features, `Gate`, `gated_fz_list`; ungated = fz_core exactly; default gate never moves), `tests/test_isoxe_gate.py` (5 tests, no data). Glue in `scratch/isoxe3/` (not committed): `build_rows.py`, `gate_cv.py`, `build_bpg.py`, `t_bpg.py`. |

## 6. Reading [I]

- **What the gate learned.** It learned mainly where *not* to move. The signals it uses (the holder in engine-1's list, GLACIER disagreeing with
  v2, a small v2 margin, a library hit) are the obvious "the list knows better" signs. That is consistent with section 8 of the
  isoxe2 review: the list's advantage is its catalogue / retrieval evidence.
- **What the data cannot show.** Whether the remaining moves gain on the hidden test. CV is a coin flip on wins / losses (10 / 11) and
  the held-out pass is 3 / 0, on a split where blind moves also gained.
- **Two mismatches to the LB base.**
  - The replay lists lack bp1's neural consensus (ranks 2-25 re-ordered by sanpier's model), so list position means something
    different there.
  - The instrument already over-rated blind a = 0.5 by about +0.006 against the LB.
- **Recommendation.** No submission on this evidence alone. If an LB slot is spare, bpg is a low-risk probe: it moves about a fifth of the
  groups bp2 moved, and almost never rank 1. The expected result is 0.477 ± one answer.
