## 0. Verdict

**Do not implement.** The pre-registered rule P1-P4 passes, but the pass is not valid evidence: the model learned to restore engine 1's
order, and engine 1 has memorised these training structures. Every variant without engine-1 features is flat or negative on the
hidden-test-like class. This is the same failure mode as `finalrank-2026-10-17.md`, reached through network leakage instead of list
construction.

## 1. What was built [V]

- **Data.** Real s1 final lists from two validation runs (800 lists, 230 with the answer at ranks 2-25):
  - **s1val**: the existing dump, 400 molecules.
  - **s1b** (new; `scratch/rerank25/build_val_b.py`): s1val's notebook with a second set. It holds the 125 NP-panel molecules that
    were class 'lib' in s1val, now class 'all', plus 275 new enveda-180 molecules, all class 'all'. So every panel structure appears
    once as a class-'all' list. The dry run checked the set on the local train. The replay identity check passed on every stage, 400 / 400.
- **Scorers.** `scores_b.py` reproduces top1lock's scorer pickles exactly on s1val (max |diff| 0).
- **Model** (`features.py`, `cv.py`). Row 1 is locked. Only E1 rows (engine-1 pool, not generated) move, and only among their own
  positions, so no provenance-class prior can be used. Model: LightGBM lambdarank, 23 features, monotone constraints, 3 seeds.
  CV: 5 Murcko-scaffold folds. Popularity, provenance and set labels are excluded.

## 3. Why it is not real (post hoc, `posthoc.py` → `cv/posthoc.json`) [V]

- **Engine 1 is an oracle on these molecules.** It ranks the answer first in **97%** of class-'all' lists (s1b 0.973, s1val 0.970),
  although the answer's library spectra were purged. s1's final list has it first in only 62-76%. Of the 230 answers at ranks 2-25,
  204 are engine 1's row 1. Engine 1's networks were trained on these structures; on the hidden test (LB ≈ 0.47) it is nowhere near this.
- **The model learned "undo the demotion of engine 1's top row".** `e1_gap` and `e1_rank` carry 93% of the gain.
- **Without engine-1 features (NOE1),** ALL is still +0.011 (65 / 13), but **HT is 0.000 [−0.004, +0.004], 6 / 7**. The whole
  remaining gain is enveda-180 (+0.023, 51 / 1); the NP panel gets −0.000 / −0.001.
- **Our scorers + position only (OURS)** give ALL +0.0075 (47 / 18), but **HT −0.0013 (4 / 7)**. Again, enveda-180 only (+0.016).
- **Our scorers without position** give HT −0.017 (2 / 21).

## 4. Reading [I]

- The honest signal left after engine 1 is removed is specific to enveda-180, and it does not reach the NP panel. It probably comes
  from close analogues in that combinatorial library: isoxe and the FP net trained on it, and engine 2 / GLACIER have strong
  in-library structure.
- On the hidden-test-like class, nothing beats s1's own order for ranks 2-25. This agrees with top1lock.
- A fair re-ranker here would need lists from a chain whose engine 1 never saw the structures, which means retraining engine 1 on
  folds. Without that, any feature that tracks engine 1 will look like a large gain.
- **Lesson for the harness:** check the upstream engine's own top-1 rate on the validation set before fitting anything on chain
  features.
