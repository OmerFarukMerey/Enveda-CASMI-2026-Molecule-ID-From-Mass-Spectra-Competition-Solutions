## 2. How it enters engine 2

`nb/embed/eng/eng_runner.py` hands a list of checkpoint paths to `casmi_engine.main`; `pv_fp.load_fp_models` puts
every file whose name contains `merged` into the merged-spectrum group and every other file into the per-spectrum
group; `logits_batch` averages the logits inside a group, `molecule_logits` then averages the two groups. So adding
`fp_single_npx4soup.pt` gives `z = ½ · [ ½ (z_s2 + z_npx4) + z_m1 ]`: the NP model replaces half of the per-spectrum
view, a quarter of the total by weight. Its logits have about twice the spread of the public per-spectrum model's
(standard deviation over the 6,930 bits 28.6 against 13.9 on the `c2` molecules), so its real share is larger;
cosine between the public and the new mixed logits: 0.965. [V] Nothing else changes: the same rankers, the same
candidates. Engine 2 never sees a joined PubChem row.

On Kaggle (`ENG_EXTRA_FPNET='goooman/casmi26-fp-npx4-soup'`): cell `nb/03_engine2.py` globs
`/kaggle/input/**/casmi26-fp-npx4-soup/**/fp_*.pt`, logs path and hash, and passes the paths to the runner
(`EXTRA_FP`). A commit run without the dataset fails (the check is outside the fallback `try`); on the scoring rerun a
missing file is recorded in `FAILS` and engine 2 runs with the public pair. `tools/build_notebook.py` attaches the
dataset when the flag is set. Cost: one more forward pass of a 36 M-parameter network per spectrum, seconds on a T4.

## 3. Side finding: missing collision energy switches engine 2's fingerprint features off

`casmi_engine.parse_ce` returns NaN for a missing collision energy (`abs(nan)` does not raise), the network gets
`ce / 100 = NaN`, and the mean over a molecule's spectra makes the whole per-spectrum view NaN. The ranker
(HistGradientBoosting) treats the fingerprint features as missing. This is the reference code, unchanged, so it
happens on Kaggle as well. [V]

| `train.parquet` source | spectra without collision energy |
|---|---|
| enveda-180, enveda-np-examples, pluskal_ms2 | 0.0% |
| massbank / riken / mona / msdial | 1.9% / 9.1% / 17.0% / 41.7% |
| spectraverse / gnps / drug_plus / masaryk | 92.4% / 100% / 100% / 100% |

Consequences:
- **Hidden test**: Enveda timsTOF spectra carry a collision energy in train (0% missing), so the features are
  presumably alive there [inference; the test file was not read].
- **Local regime**: the cached logits are finite for 158 of 373 `c2` molecules with candidates and 70 of 149 `c1`
  (all 40 enveda-180, 94 of 260 natural-product catalogue, 2 of 50 without a PubChem record, 22 of 30 other). For the
  other 58% the two arms are identical by construction. My recomputation of the public logits equals the cached ones
  exactly (largest difference 0.0), NaN pattern included.
- **Earlier statements about engine 2's fingerprint features in the mixed regime** ("the list changes by 0.03 MRR
  when the features are removed") were made with those features already missing for 58% of the molecules.

## 5. What this does and does not support

- **Admissible under the exposure rule** (`EXPERIMENTS.md`, 2026-10-05): exposure on `c2` / `c1` is at or below
  v13a's (24 ≤ 25, 6 ≤ 6). The change is in engine 2, which never lists a joined row.
- **Not demonstrated locally as a gain**: every type is within two standard errors after the fusion.
- **Leaderboard evidence**: np1 0.413 against v4b 0.409, one submission [V `docs/experiments.md`], inside the noise
  band the repository uses (pitfall 5). No public notebook uses the model; the author's team is at 0.410.
- **Interaction with the join**: none found. The join's own gain is unchanged (`dB` −0.003 ne); v13a's exposure is
  unchanged. Whether +0.004 on v4b carries over to v13a is not known.
- **Open before a final selection**: the base model's training data (section 1).

## 6. Honesty and limits

- 58% of the molecules cannot show a difference (section 3); the "finite logits" columns are the measured effect,
  the "all molecules" columns the diluted one. The hidden test presumably has no such dilution.
- None of the 380 molecules is one of the 250 NP standards (0 of 380 by InChIKey14), so the fine-tune did not see
  them; the base model very likely did, as did the public models (pitfall 10). No timsTOF natural product is in the
  regime: the population the model was tuned on, and the hidden test's, is not measured here at all.
- Local stand-ins as in `fwd-replay-2026-10-05.md`: fold-safe FPNet in the v1 engine and the PubChem list; forward
  scores are local (r 0.997 to 0.998 against a Kaggle dump). `c2` uses one emulated tie order.
- The regime has not predicted leaderboard moves of this size before; no leaderboard estimate is made.
- Not run on Kaggle: no commit run of the preset was built or pushed. The checkpoint was loaded with the engine's
  class on the CPU only.
